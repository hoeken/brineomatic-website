# Where To Buy

## Build It Yourself

Brineomatic is fully open source, so you can order and assemble the PCB yourself. The easiest way to do this is through [JLCPCB](https://jlcpcb.com), which supports ordering fully assembled boards directly from our design files.

All hardware design files (schematics, gerbers, and BOM) are available on [GitHub](https://github.com/hoeken/brineomatic).
